## 5. Outstanding issues

**Must fix before / during Phase 2A**
1. **Approved homepage not live.** Commit and push the approved build plus these docs.
2. **Two design systems coexist.** Homepage: 1440px container, `--page-gutter` clamp(16px, 2.6vw, 40px), single-row masthead, new footer. All other pages: 1280px `.wrap`, `--gutter` clamp(16px, 4vw, 40px), old header (no Cars/Tools menus, no descriptor), old footer text. Visitors see the header change when they leave the homepage.
3. **Breakpoints differ** (homepage 1439/1279/1199/1023/767/389 vs site 1099/999/899/599/479).
4. **Dead code** from the previous homepage: `fp.css` §10 (~9.7 KB) and §19 (~3.4 KB); old hero carousel in `fp.js` §8. Unused by any page now.
5. **Docs are publicly served.** Apache serves `.md` files at the web root (`README.md`, `REDESIGN-NOTES.md`, `PHASE1-HOMEPAGE-NOTES.md`, now `CLAUDE.md` and `docs/`). Add `RedirectMatch 404 (\.md$|^/docs/)` in Phase 2A (or keep docs out of the deployed branch).
6. `/tools.html` uses the old header/footer and the `info` body class.
7. Literal colours in `fp-home.css` (#FAF8F3, #DEDAD2, #D6DEDD, #A9432F, gradient stops) should become tokens.

**Content and data**
8. **Photography:** 58 of 73 article heroes are AI illustrations; most og:images have baked-in headlines. Homepage works around this with clean crops; listing and article pages still show the text-baked graphics. Needs clean official photos per the asset list in `PHASE1-HOMEPAGE-NOTES.md`.
9. **Sources blocks** missing on 35 of 73 articles (28 of 36 news stories).
10. **Pre-launch articles:** Innova Hycross "buy now or wait" guide and teaser need the accuracy-gate rewrite (launch was scheduled for 25 Nov). Currently excluded from the homepage.
11. **`data/cars.json` prices** are dated snapshots from the briefs; they need a re-check routine (the finder and Featured Cars depend on them).
12. **Provenance unconfirmed** for some in-article photos used in homepage crops (Kylaq and Seltos exteriors are labelled as AI to be safe).

**Structure (presentation only; URLs stay)**
13. Guides and comparisons split across `/guides/`, `/comparisons/` and `/reviews/`; news flat at root.
14. No Cars directory: the Cars menu points to Reviews filters and the homepage finder.
15. No search results page; no pagination on listings as they grow.
16. Article hero images have no `srcset` (largest Lighthouse cost on article pages).
17. `reindex.js` rewrites `lastmod` dates for listing pages on every run (expected; creates sitemap churn in diffs).

## 6. Recommended implementation plan — Phase 2A (awaiting approval)

Goal: one shared header, footer, width system and token set across the whole site, with the homepage unchanged.

1. **Baseline.** Push the approved build. Take reference screenshots of the homepage and one page of each type (news, brief, guide, comparison, listing, tools, info, 404) at the 8 viewports.
2. **Tokens.** In `fp.css :root`, add `--content-max-width`, `--page-gutter`, `--card-gap`, `--ember-strong`, `--ember-label`, `--petrol-panel`, `--field`, and new tokens for the card surface (#FAF8F3), card border (#DEDAD2), dek-on-dark (#D6DEDD) and ember hover (#A9432F). Point `fp-home.css` at them (no visual change).
3. **Width system.** Add `.fp-container` to `fp.css`. Make `.wrap` use the same max-width and gutter so every page aligns to 1440px. Check article reading width stays at 720px.
4. **Shared masthead.** In `apply-shell.js`, use `homeHeader(cur)` for every page, with the correct active item per section (news, reviews, comparisons, guides, culture, tools). Move masthead/dropdown/drawer CSS from `fp-home.css` to `fp.css` and the JS from `fp-home.js` to `fp.js`; remove the old `.navbar`/`.main-nav` code once no page uses it.
5. **Shared footer.** Use `HOME_FOOTER` (one-line description, Tools link) on every page; move the homepage footer width rule into `fp.css`.
6. **Breakpoints.** Adopt the homepage set for header, footer and containers; leave article/listing internals for 2B/2C.
7. **Clean-up.** Delete `fp.css` §10, §19 and the old carousel in `fp.js` after a grep confirms no page uses those classes. Give `tools.html` the shared shell.
8. **Docs exposure.** Add `RedirectMatch 404 (\.md$|^/docs/)` to `.htaccess` (and keep `docs/` in the repo).
9. **QA.** 8 viewports × homepage + each page type; homepage diffed against `docs/design-references/`; no overflow, no console errors, links/images intact; scripts idempotent; `<main>` of all 73 articles byte-identical.
10. **Deliver** changed files, screenshots and notes; stop for approval before 2B.

**Expected files touched:** `assets/fp.css`, `assets/fp.js`, `assets/fp-home.css`, `assets/fp-home.js`, `scripts/apply-shell.js`, `.htaccess`, `tools.html`, and the generated shell in every HTML page (header/footer/head only).
